# Auto-merge log

Every PR `principal-review.yml` actually auto-merged (verdict `auto-merge`,
`AUTO_MERGE_DISABLED` not set), appended automatically by that workflow
right after each successful merge. See
[`docs/agent-team-pipeline.md`](agent-team-pipeline.md) for the pipeline
this is part of. Entries are append-only, oldest first.
