## v1.1 Features

### 1. Scan Format Breakdown (High Priority)

**Description:** Show format counts (EPUB/PDF/Audiobook) in scan progress and completion message.

**Current:** `Scan complete — 37 new items added`  
**Target:** `Scan complete — 37 new items added (12 EPUB, 8 PDF, 17 audiobooks)`

**Effort:** 0.5 day  
**Risk:** Low  
**Blocking:** None — can ship immediately after v1.0

**Implementation:**
- Extend `ScanProgress.FormatCounts(epub, pdf, audiobook)`
- Map in `LibraryViewModel`
- Update SettingsViewModelTest assertions

---

### 2. Error Recovery UX (High Priority)

**Description:** Add actionable recovery steps when scan fails.

| Error Type | Message | Action |
|---|---|---|
| Permission expired | "Can't access folder X" | "Tap to re-select folder" |
| Corrupted EPUB | "Skipping 'Book Name' — invalid" | "Retry import" |
| Scan timeout | "Scan took too long" | "Re-scan now" |

**Effort:** 1 day  
**Risk:** Medium (needs error handling in multiple places)  
**Blocking:** None

**Implementation:**
- Extend `ScanProgress.Error` sealed interface
- Update UI to show retry button per error type
- Log errors to local crash log (already exists)

---

### 3. Parallel Scanning (Medium-High Priority)

**Description:** Scan multiple vault folders simultaneously with batch progress.

**Effort:** 2–3 days  
**Risk:** Low (can be feature-flagged)  
**Blocking:** None

**Implementation:**
- See `FEATURE-VAULT-SCANNING-PARALLEL.md`
- Feature flag: `parallel_scanning_enabled`
- A/B test after deploy

---

### 4. Smart Scan Resumption (Medium Priority)

**Description:** Only scan folders modified since last scan.

**Effort:** 1 day  
**Risk:** Low  
**Blocking:** None

**Implementation:**
- Store `lastScanTime` in Room per folder
- Filter folders where `now - lastScanTime > 24h`
- Fall back to full scan if no folders match

---

### 5. Scan Preview Modal (Medium Priority)

**Description:** Show items found *before* committing to library.

**Effort:** 3–4 days  
**Risk:** Medium (UI change)  
**Blocking:** None

**Implementation:**
- New composable: `ScanPreviewModal`
- Toggle: "Skip duplicates", "Filter by format"
- One-tap undo: "Remove 2 items added 2 mins ago"

---

### 6. Scan Health Dashboard (Low Priority)

**Description:** Advanced metrics for power users.

**Effort:** 2 days  
**Risk:** Low  
**Blocking:** None

**Implementation:**
- New Settings section: "Scan Health"
- Metrics: recent scan times, success rate, skipped files
- Manual re-scan trigger per vault

## Acceptance Criteria

### Scan Format Breakdown
- [ ] `ScanProgress.FormatCounts` emitted during scan
- [ ] Completion message shows format breakdown
- [ ] No regressions in existing tests

### Error Recovery UX
- [ ] All scan error states show retry button
- [ ] User can retry individual vault folders
- [ ] Errors logged to local crash log

### Parallel Scanning
- [ ] Scan time reduced by 30–50% (A/B tested)
- [ ] No race conditions in Room writes
- [ ] No UI jank during scan
